# bun-react-tailwind-template

Installez les dépendances :

```bash
bun install
```

Démarrez un serveur de développement :

```bash
bun dev
```

Exécutez le projet en production :

```bash
bun start
```

Ce projet a été créé avec `bun init` dans bun v1.3.1. [Bun](https://bun.com) est un environnement d'exécution JavaScript tout-en-un et rapide.
